本轮共观察到 **2 条真实 AI 逻辑命令提交**：自动化公网 API 冒烟 1 条、独立 Safari 操作 1 条。Safari 命令明确要求清除全部筛选，将默认研究范围的 136,380 条广告切换为 251,042 条全范围结果，并自动绘制月度广告数折线；界面指标卡中的 Python 提及数与提及率不改变该图的广告数度量。1,111 tokens 仅属于 API 冒烟那次响应，不是两次操作的合计用量；逻辑操作、可能的 HTTP 重试与供应商计费次数分别看待。

## 最终清理与复核

| 项目 | 已观察结果 | 证据与范围 |
| --- | --- | --- |
| 临时部署访问 | 服务器移除本次任务的 **1 条临时 SSH 公钥**，随后使用该密钥建立的新连接被拒绝 | 仅撤销本次临时密钥；不改变运营方原有访问。记录见 [deployment.json](evidence/cloud/deployment.json) |
| 临时文件 | 本机临时密钥、授权命令、运行配置副本和临时研究快照副本已清理；服务器传输分块及重复运行配置副本已清理 | 保留生产运行配置和正式只读研究源；原库、个人数据与密钥不进入 GitHub |
| 分析后源文件与站点 | 公网 AI/研究检查后，原库 SHA-256 仍与迁移时一致，权限为 **0440**；JobCompass 与两个既有站点均返回 **200** | 移除临时密钥后再次从外部检查健康接口，仍为 **200 / 2.1.0**；服务及证书续期定时器继续启用 |

完整研究原库已按用户明确授权私下传输到指定服务器，没有进入 GitHub。传输的 xz 为 **265,835,632 字节**，SHA-256 为 `e9f835894b38dac1a98a711a5828c10992ccab437a71a30de6d97aa17f70b8ba`；解压 SQLite 为 **2,000,760,832 字节**，SHA-256 为 `e2a6e532173643894b5cf12a6fb2b5f17c5358fb703a4209e51e55cf8fc8e61e`。本地完整解压与云端接收核对均通过，云端 `quick_check` 返回 `ok`，索引构建和公网分析前后原库哈希保持一致。压缩方式未删减研究记录；派生索引按既有有效性/快照规则生成。传输、索引、所列公网研究查询、Safari 操作及上述临时部署清理均已完成。

## 验证边界与历史材料

本轮采用原生 Python/systemd/Nginx 部署，**没有据此宣称构建 Docker 镜像或通过压力测试**。公网 HTTPS、一次续期演练、某时刻资源占用和离线测试分别证明各自检查的范围，不保证未来续期、所有自然语言解释、并发容量或招聘信息实时有效。

Safari 记录是本轮云端页面操作证据。**本轮没有重新测试云端窄屏或 CSV/JSON/PNG 导出**；这些功能沿用 v2.0/v2.1 的既有本机证据，不改称云端新验收。公网 API 中的虚构简历推荐检查也不改称新的 Safari 简历交互检查。

匿名工作空间仍是临时会话：进程重启使旧凭据失效，用户应导出需要保留的结果。数据评分是排序参考，研究指标是广告样本统计，不是整体市场需求、能力认证或录用概率。
