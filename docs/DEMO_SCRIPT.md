# JobCompass 演示与答辩脚本

## 15 分钟视频流程

| 时间 | 内容 | 画面与操作 |
|---|---|---|
| 00:00–01:30 | 问题与项目目标 | 展示岗位分散、简历比较和投递跟进的实际需求，说明单机求职辅助范围 |
| 01:30–03:30 | 简历输入 | 打开平台，载入标记为虚构的示例，展示技能原文证据和地区偏好 |
| 03:30–05:30 | 多源采集 | 展示 Remotive、Arbeitnow 的真实来源署名、采集记录及缓存；展示 CSV 模板 |
| 05:30–08:00 | 可解释匹配 | 对比实习岗位与高级岗位，解释加权 F1、TF-IDF、年限差距、地区限制、未知值 |
| 08:00–10:00 | DeepSeek 功能 | 勾选授权、执行优势提取或润色，展示后台提示和独立草稿；若服务失败则展示明确错误 |
| 10:00–11:30 | 求职管理 | 收藏岗位，标记已投递，添加备注，在看板核实并导出 CSV |
| 11:30–13:30 | 软件工程质量 | 运行 unittest，解释模块化、SQLite、异常处理、后台任务和密钥隔离 |
| 13:30–15:00 | 评估与结论 | 区分合成数据排名结果和真实联网测试，坦诚说明地区、数据质量、模型和角色限制 |

视频需要小组成员亲自参与讲解并录制。这里提供流程和讲稿提纲，不伪造已录制视频或成员参与记录。

## 5 分钟课堂演示

五页幻灯片各约一分钟：问题与功能、Python 架构、多源数据、解释性匹配、验证与边界。可以提前打开本地平台作为补充，课堂展示最多五页。

## 可重复操作步骤

为避免修改自己的真实简历，可使用独立演示库：

```bash
python main.py --db data/class_demo.db --port 8766
```

首先点击「体验示例匹配」。比较「数据分析实习生」与「Senior Python Engineer」。后者即使使用 Python，也有 6 年经验和美国地区要求。选择一个示例岗位，记录「面试中」和备注「课堂演示」，转到投递看板核实。刷新页面后状态应保留。

错误演示：输入少于 30 字符的简历并保存，页面给出错误且原先保存的简历保持不变。导入空 JSON 数组，给出错误且岗位数不变。断网后本地排序与看板仍能使用。

## 答辩问题参考

**为什么不把全部评分交给大模型？** 本地规则可重复、可解释、离线可用，避免每个岗位一次收费调用。AI 更适合解释原文和提供润色建议，而不是制造未经校准的概率。

**为什么不用纯关键词覆盖率？** 仅要求英语的岗位可能达到 100% 覆盖率，但与 Python 求职方向不符。加权 F1 同时考虑双方技能集合，并降低通用技能权重。

**是否真正支持多个招聘网站？** 已实现并实测两个公开来源。国内受限网站没有声称抓取成功，其岗位通过手动或授权文件导入进入同一流程。

**程序是否使用 AI？** 开发过程由 Codex 协助，运行时可调用 DeepSeek。要区分生成代码、自己理解验证代码和演示过程，并如实披露。

**测试通过是否代表匹配准确？** 不代表。单元测试证明明确的行为契约，12 条合成样例仅验证设计预期；真实质量需要独立标注、更广覆盖与人工评审。

**为什么同步后旧岗位得分变化？** TF-IDF 的 IDF 来自当前整个岗位语料，语料更新会改变文本权重。

**如何扩展？** 新增数据源适配器返回统一岗位模型；增加技能词典、严格条件过滤、经过评估的语义向量检索，以及更完善的数据删除与隐私保护。
