# JobCompass 研究平台界面（v2）

更新日期：2026-11-18。界面采用「左侧平台面板、右侧常驻 DeepSeek 对话栏」的工作区结构，以职业与人力资源研究为主入口，保留简历、匹配、投递和学习工具。公开模式不显示登录流程；个人工具的数据隔离由服务端访客工作空间负责，前端不把共享研究数据误称为用户的个人资料。

## 信息与视觉结构

- 左侧将「研究总览、深度研究、数据管理」与「岗位检索、简历分析、投递管理、技能成长」分组，使用统一的线性 SVG 图标。
- 左侧为平台导航与数据面板；右侧固定 360px 的研究对话栏，宽屏增至 380–400px。切换平台页面时保留对话；完成研究命令后左侧切回研究总览显示结果。
- 白色卡片、浅灰工作区、深蓝文字与靛蓝交互色；图表与查询结果占据左侧主要内容区域。既有业务页面统一使用同一套样式。
- 顶部明确当前数据集与访问方式。研究总览显示真实筛选总量、雇主标签数、探针提及数及样本提及率。
- 当前样本口径始终可见，包括共同类别、近期所见开关、来源日期与文本筛选。时间断档或类别覆盖说明显示在图表前；全部 `metadata.warnings` 可展开查看。
- 不超过 1100px 的窄屏提供「平台面板 / AI 对话」切换，避免将图表压成窄列。手机使用可展开导航、双列指标和单列图表；对话栏内的结果按钮可返回面板。
- 提供跳转主内容链接、可见键盘焦点、语义化表格、状态通知、减少动画偏好及打印样式。加载或失败时清除旧图表的辅助技术数值描述；隐藏的面板延迟初始化画布。

## 自动分析与多维交互

右侧对话栏保留实际发送的用户消息、助手执行进度、成功结果摘要与失败原因。每次分析后显示实际样本数、分组数和查询口径。对话记录保存在当前页面内存，刷新会清空，最多保留 80 条用户/助手消息；清空按钮重置对话上下文，不删除岗位或服务端分析数据。

自然语言入口执行以下流程：输入研究问题 → DeepSeek 编译受限指令 → 服务端验证并自动执行 → 返回真实聚合结果 → 更新图表、总量与表格。没有要求用户复制或手动批准 JSON 的中间步骤。高级详情仍可查看规范化指令、模型口径说明和数据元信息。

前端只向模型命令接口提交问题、所选数据集及上一次成功查询的 `query` / `totals` 上下文，不提交图表原始行。失败会清除当前结果画布，避免旧图表被当成新答案；上一次成功上下文可以用于随后纠正问题。改变数据集会清除不相容的上下文。

手动 OLAP 支持月份、季度、年份、职业类别和地区的一个或两个维度，以及广告数、雇主标签数、提及广告数和全文提及率。日期、标题、类别、地区、雇主、观察截止日和去重方式放在可展开筛选中。执行口径由服务端决定，前端显示返回的实际 `query`。

主图与 PNG 的统计标题始终由已验证的维度、指标和探针生成。模型建议标题只在高级详情中标记为建议，避免把默认探针误写为广告数量的筛选条件。

图表行为：

- 时间折线支持单序列及「时间 × 类别/地区」多序列；图例可切换序列，缩放滑块可限定显示范围。
- 缺失月份、季度和年份插入 `null`，折线不连接这些空缺；未观察到的二维组合不填零。真实观测的数值零仍按零展示。
- 条形图、交叉热力图和结果表的可点击项都转为 `exact_filters`。下钻面包屑可逐项移除，也可以重置下钻或清除全部筛选。
- 侧栏行业分布和下方时间 × 行业图使用相同的队列筛选，分别执行独立聚合。分组截断会明确提示；上方总量不能由截断图表相加推算。
- 没有可用样本、图表库未加载、接口错误或命令验证失败时显示实际空状态/错误，不补造示例图。

ECharts 6.0.0 由项目本地 `vendor/echarts.min.js` 提供，不依赖 CDN。所有 tooltip 使用 `richText` 模式；表格、标签和模型文本写入 HTML 时统一转义。模型输出不会作为 JavaScript 或任意可执行表达式运行。

## 导出

- CSV：导出当前显示的维度分组与全部四项统计量，UTF-8 BOM，正确引号转义；以公式字符开头的字符串加保护前缀。
- JSON：保存完整查询结果、实际筛选口径与 metadata，方便复核截断、分母与来源说明。
- PNG：以两倍像素比导出当前主图，并添加标题、样本总量、去重口径和解释边界说明。

导出只描述当前图表/分组，不暗示获得所有原始广告。使用 Blob 和临时对象 URL；不把原始简历或投递备注加入研究导出。

## 前后端约定

| 接口 | 用途 |
|---|---|
| `GET /api/status` | 轻量版本、部署模式与 AI 可用状态；首页不下载全部岗位正文。 |
| `GET /api/analytics/catalog?dataset=...` | 数据集、维度、指标、探针和有界分面。未选择的数据集统计可能缺省，前端不会填造零。 |
| `POST /api/analytics/query`，body 为 `{query: ...}` | 同步返回 OLAP 结果。 |
| `POST /api/analytics/command`，body 为 `{command, dataset, context}` | 自动编译与执行；可返回后台任务 ID。 |
| `GET /api/tasks/{id}` | 跟踪命令的运行/错误/完成状态。 |

结果结构包含 `query`、`rows`、`totals`、`metadata` 和可选 `pivot`；自然语言分析另有 `chart` 与 `instruction`。图表使用行中的 `value`，统计总量使用独立的 `totals`。日期语义、雇主定义和所有研究警告从 metadata 展示，不将雇主显示标签数写成已核实的公司法人数量。

全量 `/api/state` 延迟到首次访问岗位、简历、数据管理或投递页面时加载；修改业务数据后的既有刷新流程保留。`jobcompass:page` 与 `jobcompass:state` 事件负责页面激活、部署模式及图表重排。公开模式隐藏文件系统连接面板，真正的访问边界仍由服务端验证。

## 兼容与验证记录

重构保留了既有 120 个 HTML ID，未改动原有 Python 业务接口。旧的研究、学习、简历和投递事件钩子仍存在。新分析脚本使用独立闭包，避免与旧脚本的局部状态相互覆盖。

已完成 JavaScript 语法与静态 ID / 选择器对应检查；主代理已在真实浏览器验证 1440 × 1000 左平台/右对话，以及 390 × 844 的平台/对话切换。窄屏可视宽度和滚动宽度均为 390，无水平溢出；对话输入区可见。切换到技能成长页时五条对话记录仍保留，回到研究总览后继续显示。

两轮真实 DeepSeek 请求先执行季度 × 职业类别广告数量，再将指标改为 Python 全文提及率；第二轮保持前次维度和筛选，均返回 136,380 条广告的 36 个分组。主图显示三条趋势，且模型建议标题不再覆盖实际统计标题。下钻后服务器返回季度/职业类别精确筛选和月份视图，重置恢复全部样本。折线/热力图切换正常，控制台无警告或错误。

CSV、JSON、PNG 均经页面按钮实际下载；CSV/JSON 的 36 组、查询和总体数一致，PNG 为 1676 × 840 像素并已目视检查。证据、截图、范围与尚未完成的云部署见 [v2 验证记录](V2_VERIFICATION.md)。未进行所有浏览器、键盘辅助技术或云端并发的全面认证。
