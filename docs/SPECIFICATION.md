# JobCompass 软件需求与设计规格

## 目标与边界

目标用户为需要整合职位信息的求职者。本程序在单台电脑上完成简历导入、岗位归一化、排序和投递进度管理。目标是减少在多个公开数据源之间切换与手动比对的工作。用户决定投递，系统只提供参考。

范围不包含多用户账户、云同步、自动投递、登录站点反爬绕过、OCR 或招聘决策。实现以标准 Python 库为主，模块之间通过字典数据模型交互，并使用 SQLite 作为持久存储。

## 架构与数据流

浏览器发送 JSON 到 Python ThreadingHTTPServer。Application 负责输入校验与业务路由；Store 按调用开启独立 SQLite 连接，开启外键和 WAL。采集与 AI 通过最多三个线程的任务池运行，前端每 1.2 秒轮询任务结果。同类未完成任务不重复排队，最多保留约 100 条任务状态。

岗位数据进入 normalize，清理 HTML、检查必需字段、提取规范技能，然后 upsert。岗位标识为「来源与 URL」的 SHA-256 前 20 位；没有 URL 时用来源、职位、公司和地区构造标识。同源重复岗位更新内容并保留投递状态，不做跨来源合并，避免丢失出处。

简历文本与本地画像保存后，读取岗位集进行 TF-IDF 排序。AI 接收经过有限脱敏的已保存简历。旧简历对应的 AI 请求完成时，只有当前简历仍与请求原文一致，才写入最新结果。AI 草稿单独保存。

## 数据库

`jobs` 保存岗位 ID、来源、标题、公司、地区、薪资、URL、描述、技能 JSON、发布日期、采集时间、示例标记与远程标记。`applications` 以 job_id 外键保存状态、备注和更新时间。`settings` 保存简历、画像、偏好、AI 草稿与缓存时间。`collection_runs` 保存来源、状态、数量、信息与时间。

用户文本一律使用参数化 SQL。初始虚构样例只在数据库首次初始化时载入。上传文件在内存解析，不落地保存原始二进制。数据库未加密，适合单机个人使用，不能当作公网服务部署。

## 排序公式

令候选人技能集为 A，岗位识别技能集为 B。英语与沟通的质量权重为 0.2，其余为 1。加权交集质量为 M(A∩B)。技能精确率 P=M(A∩B)/M(A)，召回率 R=M(A∩B)/M(B)，技能项为 2PR/(P+R)。零交集得 0，无法识别岗位技能为未知。

文本分词使用英语单词与中文双字片段，去除少量英语停用词。TF=1+ln(count)，IDF=ln((N+1)/(df+1))+1。简历与岗位向量取余弦相似度，无文本时相似度为 0。此实现支持解释和离线演示，不宣称跨语言语义理解。

经验项：已知简历年限与已知岗位最低年限时取 min(1, candidate/required)，岗位要求 0 年则为 1。地区项按偏好词与岗位地点匹配，Worldwide／Anywhere／全球接受所有地区，不能因为 remote=True 就忽略地域约束。学历按专科、本科、硕士、博士序关系比较。

总分 = 100 × Σ(wᵢ × sᵢ) / Σ(可用项 wᵢ)。基础权重为 0.45、0.25、0.15、0.10、0.05。未识别条件不自动视为满足；界面同时显示覆盖率，避免把条件缺失误解为真实契合。

## 接口摘要

GET：`/api/state` 全状态；`/api/health` 健康；`/api/tasks/{id}` 后台任务；`/api/export` CSV；`/api/demo-resume` 虚构示例。

POST：`/api/resume` 保存；`/api/resume/file` 解析文件；`/api/resume/clear` 清除；`/api/preferences` 偏好；`/api/collect` API 采集；`/api/collect/page` 网页采集；`/api/import` 文件岗位；`/api/job` 手动岗位；`/api/application` 投递记录；`/api/ai` 大模型任务。

写入要求 `X-JobCompass: 1` 及合法 Host／Origin。错误以 JSON error 返回，HTTP 400 表示输入错误、403 表示拒绝来源、404 表示未知路径。外部任务错误存储在任务对象，UI 提示具体原因。全请求最大 7 MB。

## 评估与已知风险

离线测试覆盖真实业务边界而非只验证界面文字。合成排名评估与真实联网冒烟测试分别记录，避免混淆算法质量与服务连通性。缺失技能只是简历未体现，不表示用户不会；学历提及不一定是已取得学位；否定表达、行业隐含要求、证书、签证和多语种文本需要用户核实。

通用 URL 校验拒绝内网和保留网段，并对重定向再次验证，但 DNS 预检查与实际连接之间仍有时间差。本程序仅用于可信用户在回环地址运行，不提供公开代理服务。固定集成地址严格限定官方主机名；凭据请求拒绝重定向。重定向、DNS、网站结构及供应商模型变化仍可能导致采集失败。
