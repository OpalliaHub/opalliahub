# JobsDB 更新接口迁移验证

版本：2.1.1；日期：2026-11-19（香港时间）。本记录对应 FR34–FR35，保留原 FR14、稳定岗位 ID、投递备注和公共访客隔离。

## 原因与变更

用户提供的新版采集代码已采用 GraphQL `JobSearchV7`；平台仍请求旧 `api/jobsearch/v5/search`。本轮迁移最小搜索查询、固定三个类别及最新排序，沿用详情转换。服务端返回的页大小、搜索 token 和时间边界只在同一批次内传递，不导出到界面或日志。最多 20 个列表页、200 条详情；无效分页及重复页明确停止。

标准库传输层按请求开始时间至少间隔 1.5 秒；使用固定项目 User-Agent 和同批会话，不复制浏览器 Cookie、不轮换身份、不自动完成验证。HTTP 429/502/503/504 及明确的 GraphQL 限流最多尝试 3 次，遵守 Retry-After；单次等待最多 60 秒、整批退避最多 90 秒，超过时停止并记录服务端冷却。401/403、HTML 验证页和不支持的错误停止，不将其误报为空列表。

公开平台采用单进程采集锁，加原有共享 60 秒尝试间隔。服务端 Retry-After 截止时间在共享数据库中持久化，新 Cookie 或任务结束不缩短该等待；采集结果、备注、任务和更新记录仍属于发起访客。历史研究原库及索引不自动改写。

用户的新查询没有已验证的关键词字段。平台原关键词字段改为明确的“本批关键词筛选”：仅对本次有界最新岗位的标题、公司和正文进行不区分大小写的子串筛选，并报告未命中数量。没有忽略用户输入，也不把局部结果称为全站搜索。

## 限定

本次联网检查不能保证后续不会再遇到站点限流、接口变更或云出口限制；网站要求人工验证时，本平台停止更新并保留已有数据。离线模拟不证明网站持续可用，也不证明模型解释或岗位匹配准确率。本轮没有付费 AI 请求、全量抓取、研究库重建、扩展公开入口或并发压力测试。
