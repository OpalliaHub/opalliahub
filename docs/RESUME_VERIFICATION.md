## 本机真实岗位量级检查

只读岗位表共 7,289 条，未查询个人设置或投递备注；使用项目内虚构简历。一次功能冒烟排除 12 条演示与 24 条已过期记录，剩余 7,253 条，输出 12 个推荐，所有分数位于 0–100，优势片段来自输入原文。见 [冒烟记录](evidence/v21/corpus-smoke.json)。

随后在同一数据批次和选项下，域词匹配采用快速子串预筛并保留原正则确认，避免重复分句：完整计算 **22.811 秒 → 8.164 秒**；特征提取 **20.777 秒 → 6.238 秒**。特征哈希和完整结果哈希在该前后对照中均相同；837 个字符边界/Unicode 等价案例通过。见 [优化前](evidence/v21/performance-before.json)、[优化后](evidence/v21/performance-after.json)、[等价性](evidence/v21/performance-domain-equivalence.json)。这是单机测量，不是服务器容量或并发性能承诺。

## 真实测试先行与限制

保留初始缺失实现、无 URL 的岗位去重、技能名词列表、无时区日期、地区警告及求职意向误判的实际 red/green 记录。特别是“求职意向：Python Developer”不会被当成已掌握 Python，须由实际技能或经历句支持。项目/职责识别仍是词典和启发式规则，不保证理解全部中英文否定范围、语境与专业领域。

75/20/5 为明示规则权重，未用人工相关性标签训练；基础分在受控职业特征投影上计算，并非旧岗位检索页面的原文分。覆盖度不是置信度，提及不等于硬性要求，缺少证据不等于没有能力，分数不等于录用概率。岗位有效性仍应在原站核查。

历史 v2.0、v1.3 源码包保留；本版源码包和独立校验清单分别为 `dist/group11_project_v2.1.zip` 与 `dist/package-verification-v21.json`。门禁报告中的包 SHA 属于当次检查候选包；文档和证据归档后的最终 SHA 以独立清单为准。未进行新的 GitHub 发布、Docker 构建或云部署，也未改写历史课堂 Word/PPT。
