# JobCompass · Group 11

Version **1.1.0**, updated 8 October 2026. Download [group11_project.zip](group11_project.zip?raw=true), extract it, install requirements.txt and run `python main.py`. Open http://127.0.0.1:8765/ after starting the service.

JobsDB is now the primary source. In 数据工作台, select a keyword and 20/50/100/200 jobs, then click 更新 JobsDB 岗位 to fetch directly in the platform. Progress, cancellation, historical labels and application notes are supported. A real run saved 20 jobs; 90 local tests passed. Live availability and access depend on JobsDB.

DeepSeek is optional; configure your own key in local .env. No credentials, personal resumes or local databases are included. The bundled 28 September normalized research snapshot remains historical.

The Word/PPT course materials and group11_course_submission.zip at the repository root are the **30 September classroom revision**. Use group11_project.zip for the latest code. Source modules and the offline CI workflow are inside the ZIP; no cloud CI pass is claimed.
